# Protótipo de Rede Social — MIT App Inventor

Projeto acadêmico de uma rede social simplificada, inspirado
em funcionalidades do Instagram e desenvolvido individualmente
com programação visual em blocos no MIT App Inventor.

## Recursos implementados

- Tela de boas-vindas.
- Cadastro e login local.
- Contador de curtidas.
- Criação de publicações em texto.
- Visualização de publicações no perfil.
- Registro e visualização de comentários.
- Edição do nome do perfil.
- Armazenamento local com TinyDB.

## Tecnologias e conceitos

- MIT App Inventor.
- Programação orientada a eventos.
- Variáveis, condições e listas.
- Navegação entre oito telas.
- Persistência local com TinyDB.

## Como abrir o projeto

1. Baixe o arquivo REDE-SOCIAL.aia deste repositório.
2. Acesse https://ai2.appinventor.mit.edu/.
3. Entre na sua conta.
4. No menu Projects, selecione Import project (.aia) from my computer.
5. Selecione o arquivo baixado.

O arquivo .aia contém o projeto editável, incluindo telas,
componentes, imagens e blocos.

## Como testar

Após importar, utilize o MIT AI2 Companion ou um emulador
compatível com o App Inventor.

Roteiro sugerido:

1. Criar um cadastro com dados fictícios.
2. Entrar com os dados cadastrados.
3. Testar curtidas e comentários.
4. Criar uma publicação em texto.
5. Consultar as publicações no perfil.
6. Alterar o nome do perfil.

## Limitações

- Os dados são armazenados localmente no dispositivo.
- Não há servidor nem compartilhamento entre usuários
  de aparelhos diferentes.
- O cadastro utiliza um único par de email e senha local.
- O login é demonstrativo e não implementa autenticação segura.
- Utilize somente dados e senhas fictícios.
- O projeto não possui vínculo com o Instagram ou a Meta.
